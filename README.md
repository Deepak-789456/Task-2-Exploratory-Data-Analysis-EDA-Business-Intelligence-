# Task-2-Exploratory-Data-Analysis-EDA-Business-Intelligence-

Sales dataset data cleaning, preprocessing, outlier detection, and feature engineering using Python and Pandas.

Download or clone this repository.
Open the .ipynb file in Jupyter Notebook.
Make sure the input Excel dataset is available in the same folder as the notebook.
Run the notebook cells from top to bottom.
The cleaned dataset will be generated as Cleaned_Sales_Data.csv
